Local Haven 
A Community Support Platform

Local Haven is a community-focused website designed to connect people with local resources, assistance and volunteering opportunities.

Features
Live Form Validation: Provides inline feedback for invalid form inputs before submission.
Resource Search: Allows visitors to search community resource categories.
Community Support: Includes help request and volunteer registration forms.
Homemade Implementation: Built using HTML, CSS and vanilla JavaScript without third-party libraries or frameworks.

Technologies Used
HTML5
CSS3
Vanilla JavaScript

How to Run
Download or clone this repository.
Open the project folder.
Open index.html using Google Chrome or Microsoft Edge.
Project Status

This is a beginner-built community support platform. Form submissions currently undergo local validation but are not stored in a database. Speech recognition is experimental and is not presented as a completed feature.

Purpose
To explore how accessible web technologies can help people discover community support and connect with volunteering opportunities.
